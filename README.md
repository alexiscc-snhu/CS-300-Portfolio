# CS-300-Portfolio

## What was the problem you were solving in the projects for this course?

The main goal of these projects was to create an advising program for ABC University. The program needed to load course information from a file, display all courses in alphanumeric order, and allow the user to search for a course and view its prerequisites. In Project One, I compared different data structures to decide which one would work best. In Project Two, I used a binary search tree to create the actual program.

## How did you approach the problem? Consider why data structures are important to understand.

I approached the problem by comparing vectors, hash tables, and binary search trees. Each data structure has different benefits and drawbacks when it comes to searching, inserting, and organizing data. Understanding these differences helped me choose a binary search tree because it allowed me to search for courses and display them in alphanumeric order using an in-order traversal.

## How did you overcome any roadblocks you encountered while going through the activities or project?

One of the biggest challenges was learning how each data structure worked and how data was stored and searched. I worked through these problems by separating the code into smaller methods and testing each part individually. For Project Two, I tested loading the file, printing all courses, searching for a specific course, and handling invalid input to make sure everything worked correctly.

## How has your work on this project expanded your approach to designing software and developing programs?

These projects showed me that planning before writing code can make developing a program easier. Creating pseudocode and comparing the Big O runtime of each data structure helped me understand which structure would work best before I started Project Two. This gave me a better idea of how I should approach designing programs in the future.

## How has your work on this project evolved the way you write programs that are maintainable, readable, and adaptable?

This project helped me understand the importance of keeping code organized and easy to read. I separated different operations into their own methods, used clear names, added comments, and kept my formatting consistent. This makes the code easier to understand, test, update, and maintain.
